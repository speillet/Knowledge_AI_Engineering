# Knowledge Vault — AI Engineering

A collection of connected flashcards, learning paths and practical workshops for AI engineering: choose models, build applications, deploy them and keep them reliable.

**As of 15 November 2026**: 154 topics and 2,827 cards across 17 sections, including 377 scenarios and 211 do-not-confuse cards.

## Learn

Start with the [learning guide](docs/learning-with-flashcards.md), then follow a [reading path](00-moc-ai-engineering.md#reading-path) or browse the [topic catalog](docs/catalog.md).

Each topic combines explanations, examples, scenarios and links to related concepts. Read it in any Markdown viewer, or [open the vault in Obsidian](docs/obsidian.md) for linked navigation and spaced repetition.

## Practice

Apply what you learn with a local workshop:

- [AI decisions](examples/ai-decisions/README.md) — metrics, model selection and human review.
- [Verifiable RAG](examples/verifiable-rag/README.md) — evidence, permissions, versions and abstention.
- [Data engineering](examples/data-engineering/sql_workshop.py) — SQL, joins and time-aware features.
- [Support agent](examples/agentic-support/README.md) — tool contracts, approval and recovery tests.

For a longer project, follow the [agent platform path](docs/platform-agents-inference-learning-path.md) or the [production MLOps path](docs/production-mlops-learning-path-2026-11-12.md).

## Review with Anki

[Download the Anki package](https://github.com/speillet/Knowledge_AI_Engineering/releases/download/anki/ai-engineering.apkg) and import it into Anki or AnkiDroid. It is rebuilt after checks pass on `main`.

Reimporting updates existing notes while preserving review history. See the [Anki guide](docs/anki.md) for setup, updates, retired cards and local export. Anki and Obsidian keep separate review schedules.
