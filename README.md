# Knowledge Vault — AI Engineering

A collection of connected flashcards, learning paths and practical workshops for AI engineering: choose models, build applications, deploy them and keep them reliable.

**As of 17 November 2026**: 155 topics and 2,870 cards across 17 sections, including 382 scenarios and 215 do-not-confuse cards.

## Learn

[Browse the website](https://speillet.github.io/Knowledge_AI_Engineering/) for navigation, search and expandable answers.

Start with [your first learning session](START_HERE.md), then follow a [reading path](docs/paths/README.md) or browse the [topic catalog](docs/catalog.md).

Each topic combines explanations, examples, scenarios and links to related concepts. Read it in any Markdown viewer, or [open the vault in Obsidian](docs/guides/obsidian.md) for linked navigation and spaced repetition.

## Practice

Choose a [local workshop](examples/README.md) with documented prerequisites, commands and expected results:

- [AI decisions](examples/ai-decisions/README.md) — metrics, model selection and human review.
- [Verifiable RAG](examples/verifiable-rag/README.md) — evidence, permissions, versions and abstention.
- [Data engineering](examples/data-engineering/README.md) — SQL, joins and time-aware features.
- [Support agent](examples/agentic-support/README.md) — tool contracts, approval and recovery tests.

For a longer project, follow the [agent platform path](docs/paths/platform-agents-inference-learning-path.md) or the [production MLOps path](docs/paths/production-mlops-learning-path.md).

## Review with Anki

[Download the Anki package](https://github.com/speillet/Knowledge_AI_Engineering/releases/download/anki/ai-engineering.apkg) and import it into Anki or AnkiDroid. It is rebuilt after checks pass on `main`.

Reimporting updates existing notes while preserving review history. See the [Anki guide](docs/guides/anki.md) for setup, updates, retired cards and local export. Anki and Obsidian keep separate review schedules.
